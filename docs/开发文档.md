## 3. 核心模块实现说明

### 3.1 全局应用层（app.js）

**功能**：所有 Page 共享的全局数据和方法。

```javascript
// 核心数据结构
globalData: {
    open_id: '',           // 当前用户微信标识
    currentDeviceId: '',   // 当前选中的设备ID
    currentDeviceName: '', // 当前选中的设备名称
    baseUrl: 'http://47.109.191.13:5000'  // 后端API基地址
}

// 统一网络请求封装：自动拼接 baseUrl，统一 Loading / Toast 错误处理
request(opts) {
    // 参数：{ url, method, data, success, fail, showLoading }
    // 自动处理 statusCode 200/404/500 等
    // data.code !== 200 时自动显示后端返回的错误消息
    // 网络异常时显示"网络异常，请检查网络"
}
```

### 3.2 API 接口层（utils/api.js）

**功能**：将所有后端 API 封装为 Promise 函数，各页面直接调用。

| 函数 | 对应接口 | 说明 |
|------|----------|------|
| login(code) | POST /api/login | 微信登录 |
| bindDevice(open_id, device_id) | POST /api/devices/bind | 绑定设备 |
| unbindDevice(open_id, device_id) | POST /api/devices/unbind | 解绑设备 |
| getDeviceList(open_id) | GET /api/devices/list | 获取设备列表 |
| updateDeviceLocation(device_id, lng, lat) | PUT /api/devices/location | 更新位置 |
| getCurrentData(device_id) | GET /api/current | 获取实时数据 |
| getHistoryData(device_id, hours) | GET /api/history | 获取历史数据 |
| getDailySummary(date, device_id) | GET /api/daily_summary | 获取每日统计 |
| addFavorite(open_id, device_id) | POST /api/favorites/add | 添加收藏 |
| removeFavorite(open_id, device_id) | POST /api/favorites/remove | 取消收藏 |
| getFavoriteList(open_id) | GET /api/favorites/list | 获取收藏列表 |

### 3.3 登录页实现

#### 逻辑流程

```
handleLogin()
    ├─ wx.login() → 获取临时 code
    ├─ api.login(code) → POST /api/login
    ├─ 后端返回 open_id
    ├─ app.globalData.open_id = open_id
    ├─ wx.setStorageSync('open_id', open_id)
    └─ wx.switchTab → 跳转首页
```

#### 自动登录恢复

```javascript
onLoad() {
    const open_id = wx.getStorageSync('open_id')
    if (open_id) {
        app.globalData.open_id = open_id
        wx.switchTab({ url: '/pages/index/index' })
    }
}
```

### 3.4 首页实时数据实现

#### 数据加载流程

```javascript
onShow()
    ├─ 从缓存读取 currentDeviceId
    ├─ loadDeviceList()   → 获取设备列表（自动选中第一个）
    └─ loadCurrentData()  → 获取实时数据
        ├─ api.getCurrentData(deviceId)
        │   └─ GET /api/current?device_id=xxx
        ├─ 映射数据到页面变量
        ├─ getAQILevel(aqi) → 计算等级颜色
        └─ setData() 更新视图
```

#### AQI 等级算法

```javascript
getAQILevel(aqi) {
    if (aqi <= 50)  → '优' (绿色 #4CAF50)
    if (aqi <= 100) → '良' (黄色 #FFC107)
    if (aqi <= 150) → '轻度污染' (橙色 #FF9800)
    if (aqi <= 200) → '中度污染' (红色 #F44336)
    if (aqi > 200)  → '重度污染' (紫色 #9C27B0)
}
```

### 3.5 设备绑定实现

### 3.6 设备详情实现

#### 收藏功能

```javascript
handleToggleFavorite()

    └─ 当前未收藏 → api.addFavorite(open_id, deviceId)
```

#### GPS位置更新

```javascript
handleUpdateLocation()

    ├─ 获取经纬度
```

#### 告警阈值设置

```javascript
saveAlertSettings()

    └─ 显示保存成功
```

## 5. API 接口对接说明

### 5.1 请求响应规范

**标准请求：**
```javascript
wx.request({
    url: baseUrl + '/api/current',
    method: 'GET',
    data: { device_id: 'D001' },
    header: { 'content-type': 'application/json' }
})
```

**标准成功响应：**
```json
{
    "code": 200,
    "data": { ... }
}
```

**标准错误响应：**
```json
{
    "code": 400,
    "message": "错误描述"
}
```

### 5.2 错误处理策略

- 网络异常 → 显示"网络异常，请检查网络"
- 404 → 显示"接口不存在(404)"
- 500 → 显示"服务器错误(500)"
- 业务错误 → 显示后端返回的 message 字段

## 8. 常见问题

### 8.1 登录失败
- 检查后端服务是否运行
- 检查小程序 AppID 和后端配置的 AppID 是否一致
- 重启开发者工具

### 8.2 数据显示为"--"
- 确认设备已绑定
- 确认设备有上报数据到后端
- 检查后端 `/api/current` 接口正常返回

### 8.3 地图不显示
- 检查是否配置了 `permission.scope.userLocation`
- 检查设备是否有经纬度数据
